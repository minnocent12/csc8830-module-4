# CSc 8830: Computer Vision

## Module 4 Assignment — Submission Instructions

### 1. GitHub Repository

* Manage all source code for this assignment in a **GitHub repository**.
* Maintain a separate repository for each assignment.
* Include the **GitHub repository link** in your final PDF documentation.
* The repository must be **accessible to the instructor** at the time of submission.
* You may complete the assignment using any of the following programming languages:

  * C/C++
  * Python
  * MATLAB

---

### 2. Source Code Documentation

All submitted scripts should be clearly documented and easy to execute.

For each script:

* Include clear and meaningful comments throughout the code.
* Provide instructions explaining how to execute the script.
* Include appropriate README documentation describing:

  * The purpose of the program
  * Required dependencies or libraries
  * Setup instructions
  * How to run the application
  * Any additional information necessary to reproduce the results

> Copying the complete source code into the final PDF is **not required**. The source code should instead be available through the GitHub repository.

---

### 3. Web Application Demonstration

Create a **working web application** that demonstrates the functionality of the assignment.

Requirements:

* The assignment must be accessible through the web application.
* All assignment components must be available through the webpage.
* The web application should provide a functional demonstration of the implemented computer vision techniques or algorithms.

---

### 4. Demonstration Video

Record a video showing that the application works correctly.

The demonstration may be recorded using:

* A screen recording of the web application, or
* Properly captured footage of the working system.

The video should clearly demonstrate:

* The application running
* Relevant user inputs
* The implemented functionality
* Processing performed by the application
* Resulting outputs

The recording serves as evidence that the submitted system is functional.

---

### 5. Final PDF Documentation

Prepare a final PDF document describing your work.

The PDF should include, as applicable:

* Assignment title and identification
* Description of the problem
* Explanation of your implementation
* Methods, techniques, or algorithms used
* Examples and results
* Screenshots, figures, or visualizations where appropriate
* GitHub repository link
* Any required hand-worked solutions or examples

The complete source code does **not** need to be copied into the PDF.

---

### 6. Requirements for “Solve by Hand” or “Show by Example” Questions

For any assignment section that requires you to:

* **Solve by hand**
* **Show by example**
* Demonstrate calculations or intermediate steps manually

the work must be converted into an acceptable digital format before being included in the final PDF.

Accepted formats include:

* Typed solutions
* Scanned handwritten solutions
* Documents scanned using a camera-scanner application

The completed work must be **embedded in or appended to the final PDF documentation**.

> **Important:** Regular camera photographs of paper worksheets will **not** be accepted.

---

# Module 4 data

The RGB, thermal, and reference directories are intentionally empty in Phase 1.

- User images and large datasets are not committed by default.
- A bundled sample may be added only after its source, license/terms, and checksum are verified.
- Synthetic arrays used by automated tests are fixtures, not experimental evidence.
- Reference masks must be supplied separately and must identify the source image and alignment.

Until real inputs and references are supplied, experimental results remain pending user data
collection.
